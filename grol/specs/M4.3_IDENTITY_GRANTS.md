# M4.3 identity-authorized grants

Operator `grant add ENTITY SERVICE` resolves identity from live haobs.
Client-supplied registry_id/platform are not trusted for authorization.

```
live proven identity → authorizing:true
live unproven        → draft / authorizing:false
unknown entity       → unknown_entity
haobs down           → haobs_unavailable
```

Proposal evaluation:
```
no grant                    → not_granted
draft / live unproven       → grant_identity_unproven
live registry/domain/platform mismatch → grant_identity_drift
proven match                → pending_confirmation
operator digest confirm     → confirmed
apply                       → execute_disabled
```

Authorization and revoke follow registry_id. Revoking the current (possibly renamed) entity_id removes the stable registry grant.
No Home Assistant service call.
