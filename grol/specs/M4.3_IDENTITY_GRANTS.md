# M4.3 identity-authorized grants

A grant becomes `authorizing:true` only when registry_id, domain, and platform are present.
A proposal becomes `pending_confirmation` only when live haobs identity is proven and matches that grant.

```
no grant                    → not_granted
draft / live unproven       → grant_identity_unproven
live registry/domain/platform mismatch → grant_identity_drift
proven match                → pending_confirmation
operator digest confirm     → confirmed
apply                       → still execute_disabled
```

Authorization follows `registry_id + service`, not a frozen entity_id.
A rename with the same registry_id/domain/platform keeps the grant.
Conflicting identity fails closed.

No Home Assistant service call.
